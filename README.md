# MaltiphaseLab
🔬 Multiphase Lab
Ei repository-te Multiphase Lab-er official web application-er source code royeche. Eta ekti interactive web platform jekhane lab-er gabeshona (research), sadasyo-der talika (members), ebong gallery-r moto bisoy-guli manage kora jay.

✨ Mukhyo Boishishtyo (Key Features):
🔒 Admin Panel & Dashboard: Lab-er gorur-bhibhinno ttholyo ebong activity control korar jonno secure admin dashboard.

👤 Member Registration: Notun sadasyo-der nibondhon ba registration-er suvidha.

🧪 Research Section: Lab-er gabeshona ebong prokolpo-guli shobar jonno prokasher byabostha.

🖼️ Gallery & Uploads: Lab-er chobi ebong documents upload korar jonno dynamic upload system.

🔑 Authentication: Secure login, logout, ebong password recovery system.
